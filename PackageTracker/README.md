# מעקב חבילות

אפליקציית PWA (שרת Node + ממשק עברי) שסורקת אוטומטית חבילות כל 6–12 שעות ומקפיצה התראה כשחבילה הגיעה.

## הרצה
    npm install && npm start      # http://localhost:3000

פרוס על שרת שרץ 24/7 (VPS / Railway / Render עם דיסק) תחת HTTPS — נדרש להתראות Push. בטלפון: "הוסף למסך הבית".

## שימוש
1. **הגדרות**: הדבק קישור מעקב עם `{tracking}` ו-`{phone}`, בחר תדירות (6–12 שעות), ערוך מילות זיהוי להגעה, והפעל התראות.
2. **במעקב**: הוסף חבילות (בודדות או מרוכז: שורה לכל חבילה `טלפון מספר-מעקב שם`).
3. **הגיעו**: חבילות שזוהו; לחץ "✔ נאסף" להעברה ללשונית "נאספו".

הזיהוי: האפליקציה טוענת את דף המעקב ומחפשת מילות מפתח בטקסט. אתרים שטוענים סטטוס ב-JavaScript ידרשו קישור ל-API שלהם.
משתני סביבה: `PORT`, `DATA_DIR`, `VAPID_SUBJECT`.
